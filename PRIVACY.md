# Privacy notice (draft)

This draft describes the local release candidate and is provided for review, not as legal advice. It must be reviewed and approved by the publisher before any public release.

The candidate contains a Skills-only manifest. It does not declare Apps or MCP servers. The packaged skill is intended to process scanned exam inputs and generated digitization outputs supplied by the user. Users should inspect the skill instructions and scripts before providing confidential scans, handwriting, student information, or other sensitive data.

This packaging run did not configure telemetry, an external account, Cloud storage, or a hosted data service. That observation is limited to the local candidate files; it is not a warranty about every future runtime environment or dependency.

Users remain responsible for obtaining the permissions needed to process source scans and for removing sensitive data from support reports. Any future public release should replace this draft with a publisher-approved notice and a verified public URL.
