# Support

This is a local pre-publication candidate. A public support address or issue tracker has not been confirmed, so no contact identity is invented here.

## Before asking for help

Please include:

1. plugin version (`1.0.0`),
2. operating system and Python version,
3. the exact review-test or skill command used,
4. the complete error text, and
5. whether the input contained confidential scans, handwriting, or personal data.

Do not attach confidential exam scans or personal data unless the eventual publisher explicitly provides a suitable private support channel.

## Scope

Support for the candidate covers packaging, manifest validation, source-tree fidelity, and documented skill behavior. It does not promise a hosted service, an external connector, or a particular account/Cloud/Platform integration.
